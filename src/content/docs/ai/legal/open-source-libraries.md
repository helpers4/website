The helpers4 plugins have **no dependencies**: a skill is a folder of Markdown files that the assistant reads. Nothing is installed or run in your project besides what the assistant itself does with your agreement.

## Formats followed

| Format | Used for |
|---|---|
| [llms.txt](https://llmstxt.org) | The machine-readable references the skills read first ([details](/ai/llms/)) |
| [Claude Code plugins](https://code.claude.com/docs/en/plugins) | The marketplace and plugin manifests of helpers4/ai |

## Names

Claude and Claude Code are products of Anthropic, and GitHub Copilot is a product of GitHub. helpers4 is an independent project: these names are used only to say which assistants the plugins work with.
