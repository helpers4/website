Utility functions for working with geography operations.

## Functions

| Function | Description |
|----------|-------------|
| [`distance`](./distance/) | Great\-circle distance between two WGS84 points, in kilometres \(haversine formula, mean Earth radius of 6371 km\)\. |
| [`isWithinDistance`](./iswithindistance/) | Whether a point lies within a radius of a center, the border included\. |
