| [`isHostname`](../categories/guard/ishostname/) | [guard](../categories/guard/) | Checks whether a value is a syntactically valid DNS hostname \(RFC 952, RFC 1123, RFC 3696 section 2\)\. A label never starts or ends with a hyphen\. \- The whole name is at most 253 characters \(not counting an optional trailing dot\)\. \- A single label is valid \(\`localhost\`\)\. \- The last label \(the TLD\) is never all digits \(RFC 3696\), so \`192\.168\.0\.1\` and \`123\` are not hostnames\. | [`parseDeb822`](../categories/package/parsedeb822/) | [package](../categories/package/) | Parses a deb822 document, the format of Debian \`Packages\`, \`Sources\` and \`Release\` indexes, \`control\` and \`\.dsc\` and \`\.changes\` files, DEP\-5 \`copyright\` files and apt \`\.sources\` files, as described in the Debian Policy Manual, chapter 5\.1 "Syntax of control files"\.  \- Stanzas are separated by one or more blank lines \(lines holding only whitespace\)\. \- A field is \`Name: value\`\. The value has its surrounding whitespace removed\. Names are   case\-insensitive in Debian: the original spelling is kept in \`entries\`, and \`fields\` is keyed   by the lower\-cased name\. \- A line starting with a space or a tab continues the previous field\. Exactly one leading   space or tab is removed, the line breaks are kept \(joined with \`\\n\`\), and a continuation line   that is just \`\.\` stands for an empty line\. A field whose first line is empty \(\`Files:\`\) keeps   that empty first line, so its value starts with \`\\n\`\. \- Lines starting with \`\#\` are comments and are ignored anywhere, without ending a stanza or a   multi\-line value\. \`\\r\\n\` line endings are accepted\. Trailing whitespace is dropped\. \- A repeated field name inside one stanza: all occurrences stay in \`entries\`, and the last one   wins in \`fields\`\. \- A line that is not a comment, a field or a continuation \(no colon, a continuation before any   field, a name with a space before the colon\) never throws by default: it is collected in the   stanza's \`unparsed\`, so nothing is lost silently\. With \`\{ strict: true \}\` it throws a   \`SyntaxError\` naming the line number and its text instead\. A stanza made only of such lines   is still returned\. \- PGP clearsigning armor \(\`Release\`, \`\.dsc\`, \`\.changes\` can be signed\) is not interpreted\.  To compare the version strings found in \`Version\` fields, use \`compare\(a, b, 'debian'\)\` from \`@helpers4/version\`; to read \`Depends\`\-like fields, use \`parseDependencies\`\. |
| [`parseDependencies`](../categories/package/parsedependencies/) | [package](../categories/package/) | Parses the value of a package dependency field \(\`Depends\`, \`Requires\`, \`depends\`, \.\.\.\) into a structure: groups of alternatives, each alternative a name with an optional version constraint\. \`format\` says how the text is written, and decides the exact shape of each dependency and the operator spellings \(see DependencyFormats\); the options are those of that format only\.  \*\*\`'debian'\`\*\* — a relationship field of the Debian Policy Manual, chapter 7\.1 \(\`Depends\`, \`Pre\-Depends\`, \`Recommends\`, \`Suggests\`, \`Enhances\`, \`Breaks\`, \`Conflicts\`, \`Provides\`, \`Replaces\`, \`Build\-Depends\`, \.\.\.\)\. Commas separate the entries that must all hold \(AND\), \`\|\` separates the alternatives inside an entry \(OR\)\. Each alternative is \`name\[:arch\] \[\(op version\)\] \[\[archs\]\] \[<profiles>\]\`, in that order, with any whitespace \(line breaks included, as in a multi\-line \`Depends\`\) between the parts\. The operators are Debian's \`<<\`, \`<=\`, \`=\`, \`>=\` and \`>>\`, kept as written; the obsolete \`<\` and \`>\` throw unless \`options\.compat\` is set, in which case they are read as \`<=\` and \`>=\` like dpkg does\. Whitespace\-only entries \(a trailing comma, \`a,, b\`\) are skipped, as dpkg does\. The \`$\{substvars\}\` of source \`debian/control\` files are not supported\.  \*\*\`'rpm'\`\*\* — an RPM \`Requires\` value: capabilities separated by commas and/or whitespace, each \`name \[op version\]\` with \`<\`, \`<=\`, \`=\`, \`>=\` or \`>\`; boolean dependencies \`\(a or b\)\` give the alternatives of a group\.  \*\*\`'arch'\`\*\* — an Arch Linux \`depends\` array or \`\.PKGINFO\` list: entries separated by whitespace \(quotes and surrounding parentheses of a PKGBUILD array are accepted\), each \`name\[op version\]\`\.  \*\*\`'alpine'\`\*\* — an Alpine \`depends\` list: entries separated by whitespace, each \`\[\!\]name\[op version\]\` \(\`\!\` is a conflict\)\.  \*\*\`'pep508'\`\*\* — PEP 508 requirements, one per line \(as in \`requirements\.txt\` or the \`dependencies\` of a \`pyproject\.toml\`\): \`name\[extras\] specifiers ; marker\`, or \`name @ url\`\.  Every entry that is not valid throws a \`SyntaxError\` quoting the offending text\. Parsing is linear in the input\. |
| [`parsePath`](../categories/geometry/parsepath/) | [geometry](../categories/geometry/) | Parses SVG path data \(the \`d\` attribute\) into commands, as written: the letters keep their case \(absolute or relative\), \`H\`/\`V\`/\`S\`/\`T\`/\`A\` stay what they are, and a command repeated without its letter \(\`L 1 2 3 4\`\) becomes one command per set of numbers \(\`M\` repeats as \`L\`, \`m\` as \`l\`\)\. | [`deobfuscate`](../categories/string/deobfuscate/) | [string](../categories/string/) | Reverses obfuscate\. Never throws: a token that \`obfuscate\` could not have produced \(another alphabet, padding, broken length, bytes that are not UTF\-8, not a string\) gives \`null\`\. |
| [`isValid`](../categories/version/isvalid/) | [version](../categories/version/) | Whether \`version\` is a valid version in the given \`scheme\`\. Never throws: any input that is not valid, a non\-string included, gives \`false\`\.  \*\*\`'semver'\`\*\* \(default\) — SemVer 2\.0\.0, strictly: \`MAJOR\.MINOR\.PATCH\` with no leading zeros, an optional \`\-prerelease\` \(numeric identifiers without leading zeros\) and an optional \`\+build\`\. Unlike parse, which reads anything, and unlike compare, a leading \`v\` is refused by default \(\`v1\.2\.3\` is a git tag, not a version; see IsValidOptions\.prefix to accept or require it\), and so are \`1\.2\` and \`1\.2\.3\.4\`\.  \*\*\`'gentoo'\`\*\*, \*\*\`'debian'\`\*\*, \*\*\`'rpm'\`\*\*, \*\*\`'pacman'\`\*\*, \*\*\`'pep440'\`\*\* — whether parse accepts it \(these schemes throw on invalid input, so their grammar is the one \`parse\` documents\)\.  \*\*\`'maven'\`\*\* — any non\-empty string: Maven reads every text as a version\. |
| [`obfuscate`](../categories/string/obfuscate/) | [string](../categories/string/) | Hides a text from anything that reads the raw page source: the text is reversed \(by Unicode code point, so emoji stay whole\) and written as unpadded base64url\. Typical use: an e\-mail address rebuilt on click, so naive scrapers do not find it\. deobfuscate reverses it\.  It works the same in Node\.js and in browsers \(no \`Buffer\`, no \`btoa\`\), for any text, non\-ASCII included\. A lone surrogate, which is not valid text, comes back as U\+FFFD\.  \*\*This is not security\.\*\* It only stops scrapers that look at the HTML as it is; anyone can undo it\. Never use it for secrets\. |
| [`sortVersions`](../categories/version/sortversions/) | [version](../categories/version/) | Sorts version strings by version, not by text \(\`1\.10\.0\` after \`1\.9\.0\`\), in the given scheme: the same as \`versions\.sort\(\(a, b\) => compare\(a, b, scheme\)\)\`, without mutating the input\. Versions that compare as equal keep their order\. Strings are returned as they were written \(a \`v\` prefix stays\)\.  Every version is compared with compare, so in the schemes that throw on invalid input \(\`'gentoo'\`, \`'debian'\`, …\) a bad version throws a \`SyntaxError\`: filter with isValid first\. |

Uses the same path syntax as get/set\.  A missing intermediate segment is a no\-op \(nothing to remove\), not an error\. As with \`set\`, any path containing a string segment equal to \`\_\_proto\_\_\`, \`constructor\`, or \`prototype\` is rejected and the object is returned unchanged\.  The removed key stops appearing in \`Object\.keys\`/\`for\.\.\.in\` — unlike setting it to \`undefined\`, which would keep the key present\. |
| [`update`](../categories/object/update/) | [object](../categories/object/) | Updates the value at a path by applying a function to its current value, creating intermediate objects as needed\. Equivalent to \`set\(obj, path, updater\(get\(obj, path\)\)\)\` in a single call\.  Uses the same path syntax and type\-inference rules as get and set — see those for the full behavior \(string vs\. \`PropertyKey\[\]\` paths, prototype\-pollution guarding, etc\.\)\. |
| [`ValueOf`](../categories/type/valueof/) | [type](../categories/type/) | Produces a union of all value types of an object type \`T\`\. |
